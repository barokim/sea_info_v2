# 신고 ‘기타 설명’ 관리자 화면 연결 안내

이종민 님께 전달하는 안내입니다.

각자가 맡은 파일만 관리하자는 팀내의 규칙에 따라 이종민님께 수정해야하는 사항을 안내드립니다.
사용자가 게시글을 신고 할 때 '기타'를 선택했을 시 신고 설명 내용이 저장되어지지 않는 문제와 관리자 전용 페이지에서 조회되지 않는 문제를 수정했습니다.
따라서 설명 저장과 관리자 전용 조회 API를 구현했습니다. API나 DB를 새로 만들 필요 없이, 관리자 화면에서 준비된 함수를 호출하면 됩니다.
이종민님이 맡은 파일을 수정해야 하는 부분은 다음과 같습니다. 

## 1. 수정할 곳

`views/admin/posts.py`의 **‘신고 처리’ → 게시글 미리보기 아래, ‘숨기기·문제없음’ 버튼 위**에 설명을 표시해 주세요.

파일 위쪽에 다음을 추가해 주세요. 이미 있는 import는 중복으로 넣지 않아도 됩니다.

```python
from services import community_data as community_api
from services.api import ApiError
```

각 신고 카드 안에 아래 코드를 넣으면 됩니다.

```python
with st.expander("기타 신고 설명"):
    try:
        reports = community_api.report_details(r["post"])
        descriptions = [
            item for item in reports
            if item["status"] == "대기" and item["detail"]
        ]

        if not descriptions:
            st.caption("등록된 기타 설명이 없어요.")

        for item in descriptions:
            st.caption(item["created_at"])
            st.write(item["detail"])

    except ApiError as e:
        st.warning(e.message)
```

- `r["post"]`: 현재 카드에 표시된 게시글 번호
- `detail`: 사용자가 입력한 기타 설명
- `created_at`: 신고가 접수된 날짜와 시간
- `status == "대기"`: 아직 처리하지 않은 신고만 표시한다는 뜻

로그인 정보는 함수가 자동으로 전달해요. 관리자 계정만 조회할 수 있습니다.

## 2. 준비된 조회 방법

| 용도 | 호출할 함수 | 연결되는 API |
|---|---|---|
| 게시글에 접수된 신고 목록 | `community_api.report_details(게시글번호)` | `GET /admin/community/report-details?post_id=게시글번호` |
| 신고 한 건 조회 | `community_api.report_detail(신고번호)` | `GET /admin/community/reports/신고번호/detail` |

목록은 기본 최신 50건이에요. 위 예제도 최신 50건 중에서 미처리 설명을 표시합니다.

더 필요하면 `limit=100, offset=0`으로 요청하고, 다음 묶음은 `offset=100`으로 조회할 수 있어요. 한 번에 최대 100건까지 조회합니다.

```python
reports = community_api.report_details(r["post"], limit=100, offset=0)
```

## 3. 확인 방법

1. 기타 설명 기능이 포함된 코드를 공유받고 서버를 재시작해요.
2. 일반 회원으로 로그인해서 다른 사람의 게시글에 ‘기타’ 신고와 설명을 작성해요.
3. 관리자로 로그인해 ‘게시물·신고 관리’ 화면을 열어요.
4. 해당 신고 카드의 ‘기타 신고 설명’을 펼쳐 입력한 설명이 보이는지 확인해요.

설명을 입력하지 않았거나 기능 추가 전에 접수된 신고는 빈 값으로 나오는 것이 정상이에요. 예전에 저장되지 않았던 설명은 복구되지 않습니다.

기존 ‘숨기기·문제없음’ 처리 기능은 그대로 사용하면 됩니다.
