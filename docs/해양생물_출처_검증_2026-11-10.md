### 이미지 파일명 인식 보완 및 출처별 기본 허용 검토

- 개별 MABIK 게시물의 공공누리 표시 영역에 `kogl_mark_01.png` 같은 제1유형 로고가 **이미지 파일명만으로** 표시될 경우도 판별하도록 담당 `backend/mabik_news.py`를 보완했다. 다른 유형의 로고가 함께 있으면 차단한다. 구문 및 이미지 경로 인식 시험을 통과했다. 실제 사이트 재실행은 중단되어 아직 확인하지 못했다.
- 출처별 기본 허용·금지 키워드 방식은 적용하지 않았다. MABIK 공식 정책은 공공누리 미표시 자료의 사전 협의를 요구하고, NIFS 공식 정책도 공공누리 미적용 자료의 별도 협의 또는 허락을 요구한다. 부정 표시가 없다는 사실만으로 제1유형이나 AI 요약·재배포 허락을 입증할 수 없다.

- **[신규]** `backend/mabik_news.py`: MABIK 보도자료 상세의 `content-info` 공공누리 영역에서 명시적인 제1유형 텍스트 또는 이미지 대체 텍스트를 확인한다. 표시가 없거나 유형이 충돌하거나 텍스트 본문을 분리할 수 없으면 수집하지 않는다.
- 담당 `backend/news_collector.py`와 `jobs/collect_korea_preview.py`에 MABIK을 기사별 판별 출처로 연결했다. 제1유형 통과 글만 텍스트 수집·AI 요약·담당 미리보기 뉴스 DB 등록 대상으로 삼는다. 이미지·첨부물은 포함하지 않는다.
- 실사이트 수동 실행 결과: MABIK 목록 10건 중 해양 관련 제목 6건을 개별 확인했고 6건 모두 제1유형 표시가 없어 건너뛰었다. NIFS·정책브리핑 오류 0건, 새 기사 0건, 종료 코드 0.
- MEIS ‘이달의 해양생물’은 현재 연도 자료 0건이다. 기존 월별 자료는 포스터 중심이고 개별 텍스트 기사·제1유형 표시를 확인할 수 없으므로 자동 통과 대상이 없다. 새 항목 발견 시에도 권리 및 텍스트 구조가 확인되지 않으면 건너뛴다.
- 다음 오전 6시 예약 작업은 같은 스크립트를 실행한다. 실제 예약 실행 결과는 실행 이후 확인해야 한다.

- 기존 오전 6시 예약 작업 `SeaInfoJungKoreaNewsPreview`가 실행하는 담당 스크립트에 MABIK·MEIS 목록 확인을 추가했다. NIFS 및 정책브리핑의 기사별 권리 확인 수집도 계속 실행한다.
- **[신규]** `backend/pending_source_monitor.py`: MABIK 목록 제목·날짜·원문 주소를 확인하고 MEIS는 현재 연도 월별 목록을 확인한다. 본문·이미지·요약은 읽거나 저장하지 않는다.

## 남은 위험

- HTML 구조 또는 공공누리 표시 방식이 바뀌면 파싱이 실패하거나 글이 제외될 수 있다. 제목 단어 기반 필터는 해양생물 글을 놓치거나 관련성이 약한 글을 통과시킬 수 있다.
- 오전 6시에 확인하는 것은 매일 새 글이 나온다는 보장이 아니다. 목록 첫 페이지 밖으로 밀린 글은 놓칠 수 있다. 고유 링크의 조회 날짜 범위는 2030년 말까지 고정해 중복을 막았다.
- AI 요약은 수치·사실 오류가 생길 수 있어 공개 배포 전 검토가 필요하다. 사용 중인 DB와 예약 작업은 담당 로컬 미리보기용이며 배포 서버에는 별도 적용이 필요하다.
